# Serena Cersea — Safe Release Candidate v0.7

Технически очищенная версия публичной мультиссылочной визитки.

## Что изменено

- удалена внешняя загрузка Google Fonts;
- сайт использует локальные системные шрифты;
- неактивный Snapchat удалён;
- блок мессенджеров переименован в нейтральный `Contact`;
- Telegram ведёт только в личный чат;
- добавлены Open Graph и X/Twitter Card метаданные;
- создано отдельное нейтральное превью `serena-cersea-share.jpg`;
- внешним ссылкам добавлена защита `noopener`, `noreferrer` и `no-referrer`;
- созданы черновики `privacy.html` и `impressum.html`;
- юридические страницы помечены `noindex` и не готовы к публикации.

## Активные публичные платформы

- Instagram
- Facebook
- X
- TikTok

## Активные способы связи

- Telegram
- Signal
- WhatsApp

## Важно перед публикацией

1. Заполнить Impressum настоящими юридическими данными.
2. Завершить Privacy после выбора домена и хостинга.
3. Добавить отдельную деловую электронную почту.
4. После покупки домена добавить абсолютные `canonical`, `og:url` и абсолютный адрес `og:image`.
5. Проверить кадрирование и все ссылки на телефоне и компьютере.

## Как открыть

Откройте папку в Visual Studio Code и запустите `index.html` через Live Server.


## Версия v0.8 — восстановленный визуальный стиль

Внешний вид полностью возвращён к версии v0.6:

- снова используется Cormorant Garamond для редакционных заголовков;
- снова используется Manrope для интерфейса;
- восстановлены прежние пропорции, интервалы и журнальная типографика;
- сохранены все функциональные и безопасные изменения v0.7.

Важно: шрифты снова загружаются через Google Fonts, чтобы сохранить выбранный дизайн.
Перед окончательным публичным запуском нужно будет решить вопрос их локального размещения
или выбрать равноценные локальные шрифты без потери визуального качества.
